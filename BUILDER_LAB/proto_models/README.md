# Proto Models

This folder contains exploratory structural models that are not yet part of the formal NEXAH framework, but may become future extensions of it.

Proto models are used to:

- capture emerging geometric insights
- stabilize new conceptual structures
- connect visual intuition with framework language
- prepare possible migration into `CORE_GEOMETRY` or later into `RESEARCH`

These files should be treated as **proto-framework concepts**:
structurally relevant, but not yet finalized as theorems or formal research results.

---

## 🧠 Purpose

The NEXAH framework currently distinguishes between:

- **RESEARCH** → strict formal / discrete foundations  
- **FRAMEWORK / CORE_GEOMETRY** → established geometric and field structure  
- **BUILDER_LAB** → experimental and exploratory work  

The `proto_models` folder sits between exploration and framework integration.

It is intended for ideas that are:

- more developed than loose notes
- structurally coherent
- already connected to NEXAH concepts
- not yet mathematically closed
