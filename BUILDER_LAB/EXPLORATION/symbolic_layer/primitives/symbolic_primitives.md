- reusable across all symbolic constructs and systems

# 🔹 Core Primitives

---

## 1. Flow

### Definition

```text
Directional movement induced by the field
```

### Field Mapping

- gradient component (∇ρ)
- system velocity

---

## 2. Channel

### Definition

```text
Preferred pathway through state space
```

### Field Mapping

- ridges / high-density paths
- transport corridors

---

## 3. Basin

### Definition

```text
Region of convergence
```

### Field Mapping

- attractor region
- stable density maximum

---

## 4. Gate

### Definition

```text
Entry region into a basin
```

### Field Mapping

- low-barrier transition point
- weak stability region

---

## 5. Switch

### Definition

```text
Boundary crossing between regions
```

### Field Mapping

- separatrix
- interface zone (C ≈ 0)

---

## 6. Spiral

### Definition

```text
Rotational motion within the field
```

### Field Mapping

- curl component (∇ × F)
- orbit / looping behavior

---

## 7. Pulse

### Definition

```text
Time-dependent modulation of the field
```

### Field Mapping

- oscillatory forcing
- temporal variation (e.g. Janus, Lyapunov)

---

## 8. Sheet

### Definition

```text
Layered structure within state space
```

### Field Mapping

- phase layers
- regime-dependent regions

---

## 9. Gate Direction

### Definition

```text
Orientation required to pass a gate
```

### Field Mapping

- directional flow alignment
- anisotropic transition condition

---

# 🔁 Composition Principle

Complex symbolic constructs are built from primitives:

```text
Channel + Gate → Entry Path
Switch + Direction → Transition Mechanism
Spiral + Basin → Stable Loop
Pulse + Flow → Modulated Motion
```
