# NEXAH Library Documentation

The documentation in this directory helps a human reader enter and navigate
the visual NEXAH Library. It does not replace the Canonical Library Registry or
the public Are.na source.

## Entrance hall

Begin with **[THE ATLAS OF ATLASES](atlas-of-atlases/README.md)**. It introduces
the recurring visual grammar, the six orientation fields, their transitions,
and the Library appendix before a reader enters individual Works.

```text
THE ATLAS OF ATLASES
→ six atlas fields
→ Library appendix
→ wider NEXAH Library
```
