# Atlas documentation assets

`../images/` contains 1200-pixel Are.na presentation variants used by this
documentation module. They are ordered by observed public source position and
named with their stable Are.na Block IDs.

`source_manifest.yaml` records:

- public Channel and Block identity;
- source position and source title;
- local filename, byte count, and SHA-256 digest;
- canonical sequence membership or supplemental status.

The files are documentation copies, not a replacement source archive. Are.na
remains authoritative for the original visuals and live publication sequence.
The editorial reading order is declared separately because it may intentionally
differ from public source position.
