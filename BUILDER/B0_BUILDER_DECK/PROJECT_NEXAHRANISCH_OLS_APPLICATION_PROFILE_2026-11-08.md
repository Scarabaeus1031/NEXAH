## Goal

Make the existing Orientation Language useful in a small, inspectable Human
and machine-readable application profile. The profile should help a person or
adapter describe one bounded situation, compare views, retain a residual and
return a decision without pretending that the representation is the whole
situation.

```text
SOURCE
→ CARRIER
→ VIEW / CUT
→ TYPED RELATION
→ TRANSITION
→ RESIDUAL
→ RETURN / ABSTAIN / STOP
→ HUMAN DECISION
```

## Meaning of the working label

`Nexahranisch` is a Builder and editorial working label for an OLS-compatible
application profile. It is not:

- a new natural language;
- a new normative OLS term or OLS 1.0 extension;
- a trained language model;
- a scientific result, ontology merger or universal translation system.

An LLM may later consume or produce profile records only through a declared
adapter. Its prose never becomes source authority, and uncertainty must be
returned as `ABSTAIN`, `OPEN` or `STOP` rather than smoothed away.
