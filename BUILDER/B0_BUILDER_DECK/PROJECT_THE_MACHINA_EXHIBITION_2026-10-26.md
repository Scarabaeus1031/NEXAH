## Project decision

THE MACHINA is recorded as an existing A0 Builder project for a curated
exhibition. This project reuses the current THE MACHINA flagship and the
existing identity `NEXAH_A0_ORIENTATION_CONTROLLER_BENCH`; it creates no new
Machine family, Navigator node, Study, evidence relation or publication state.

The exhibition should make the existing Machine corpus readable without
turning the technical Bench into the public experience.

## Goal

Create one bounded exhibition in which a visitor can move from a small visible
selection into deeper source material and return to the last orientation
point:

```text
EXHIBITION
  -> MACHINE SERIES
  -> PARTS SHELF
  -> BENCH
  -> HUMAN RETURN
```

The visible finish is a guided installation with a clear beginning, a limited
number of deliberately opened rooms and an explicit close/Return at every
depth.

## Curatorial grammar

The recurring Machine material already supports one stable reading:

```text
CARRIER + FRAME
  -> APERTURE / CUT
  -> VIEW / PROJECTION
  -> RELATION / COMPARISON
  -> RETAINED + LOST + INTRODUCED + UNRESOLVED + RESIDUAL
  -> RECORD
  -> HUMAN RETURN
```

This is an exhibition and Orientation grammar. It is not a universal runtime,
new OLS operator, common physical mechanism or scientific result.

## Four doors

1. **Exhibition** — the three large bodies and a short installation sequence.
2. **Machine Series** — a curated subset of the existing 30-card draft route.
3. **Parts Shelf** — the nine checksum-bound models, opened only by choice.
4. **Bench** — sources, controls, tests and technical connections.

The first visit should not expose all four depths at once. The exhibition opens
the next door only when the visitor chooses it. Closing a room returns to the
previous point; no long reverse scroll is required.
