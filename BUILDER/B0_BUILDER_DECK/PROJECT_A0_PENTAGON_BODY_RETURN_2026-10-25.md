## Target experience

A 60–90 second guided human view that demonstrates one body, one controlled
movement, one projection and one explicit return problem:

`SOURCE BODY -> MOVE -> PROJECT -> COMPARE -> RETURN / CANNOT RETURN`

1. same image;
2. same pose;
3. same recoverable record.

The Pascal `-60° / +60°` ambiguity is the explanatory hinge. Visual equality
must never be presented as state identity.
