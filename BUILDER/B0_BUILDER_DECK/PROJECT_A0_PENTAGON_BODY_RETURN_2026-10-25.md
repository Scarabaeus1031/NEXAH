## Target experience

A 60–90 second guided human view that demonstrates one body, one controlled
movement, one projection and one explicit return problem:

`SOURCE BODY -> MOVE -> PROJECT -> COMPARE -> RETURN / CANNOT RETURN`

The minimum useful cut shows three labels at all times:

1. same image;
2. same pose;
3. same recoverable record.

The Pascal `-60° / +60°` ambiguity is the explanatory hinge. Visual equality
must never be presented as state identity.

## Host decision

Recommended host order:

1. **Pentagon / Lantern source viewer** — owns body, movement and records;
2. **THE MACHINA viewer** — later receives the curated human-facing cut;
3. **Blue Body / Blue Pink** — contextual doorway only;
4. **Science Desk** — evidence, claim boundary and receipt return;
5. **Mission Control** — priority, release and publication decision.

Do not make the Bench the primary exhibition host. Do not make Blue Body the
source owner of the Lantern. The source viewer must work before a flagship
shell is added.
