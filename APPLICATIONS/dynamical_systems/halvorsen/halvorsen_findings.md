# NEXAH — Foundations (Working)

Status: PRE-FORMAL  
Scope: Cross-system (Halvorsen, Lorenz, IEEE, …)

---

## 1. CORE PRINCIPLE

```text
Systems do not move randomly in state space.

They move within a structured field
organized into regimes,
connected via constrained transitions.
```

---

## 2. FIELD STRUCTURE

### Hypothesis

```text
field = set of overlapping flow sheets
```

### Properties

- local coherence
- directional flow
- density variation
- stability basins

---

## 3. REGIMES

### Definition

```text
regime = locally coherent flow region
```

### Observed Properties

- stability (attraction)
- coherence (aligned motion)
- persistence (time stability)

---

## 4. TRANSITIONS

### Core Law

```text
transitions are geometry-driven, not random
```

### Properties

- smooth
- directional
- constrained
- sparse

---

## 5. GATES

### Working Definition

```text
gate = low-density + flow-conflict region
```

### Interpretation

- transition enabler
- structural bottleneck
- control leverage point

---

## 6. RESIDUE STRUCTURE

### Observation

```text
continuous flow → discrete residue classes
```

### Properties

- cyclic structure (Halvorsen)
- switching structure (Lorenz)
- predictive signal present

---

## 7. MASS CONSERVATION

### Law

```text
Σ P(B_i → B_j) = 1
```

### Interpretation

- no drift
- closed probabilistic system
- stable transition dynamics

---

## 8. CONTROL PRINCIPLE

```text
control = alignment + topology modification
```

```text
control ≠ brute force steering
```

## 9. NAVIGATION

           + use gates
