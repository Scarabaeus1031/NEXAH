# Stability Assessment

## Mature practices within the current repository

“Mature” here means consistently executed and inspectable across the current corpus, not externally validated.

| Practice | Basis | Boundary |
|---|---|---|
| source/corpus fixation | all pilots and governed comparisons | one dominant source type and analyst |
| provenance and traceability | recurring explicit artifacts | does not prove scientific correctness |
| plural representation | all pilots; repeated in studies | no universal representation categories |
| evidence/editorial/unsupported separation | pilots, reflections, neighborhoods, studies | analyst classification remains influential |
| explicit limitations and non-claims | recurring across artifact classes | reader recognition untested |
| negative decision preservation | rejection, stopping, no-match, incomparability, non-reciprocity | consistency across analysts unknown |
| immutable-input comparison discipline | comparison framework and execution | only one executed pair |
