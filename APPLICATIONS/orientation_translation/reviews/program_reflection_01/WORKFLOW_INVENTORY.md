# Workflow Inventory

## 1. Pilot construction — recurring across three cases

```text
fixed source
→ source record / observations
→ bounded representations
→ local comparison
→ reader questions and routes
→ Reader + Explain artifacts
→ evaluation / report / traceability
```

Stable aspects: source fixation, plural representations, non-ranked routes, evidence limits, and traceability.

Variable aspects: number and type of representations, route count, comparison topology, local modifications, and boundary granularity.

## 2. Post-pilot reflection — recurring across three cases

```text
frozen pilot
→ separate reflection
→ emergent observations
→ hidden questions
→ candidate bridges
→ orientation-gain question
```

The Reflection does not modify the frozen source or pilot. Whether it discovers or editorially constructs each question is recorded rather than resolved universally.

## 3. Neighborhood construction — recurring across three cases

```text
frozen pilot + reflection
→ candidate local relations
→ support and role classification
→ direction / reverse review
→ admission or rejection
→ non-transitivity check
→ stopping record
→ frozen neighborhood
```

P01 uses retrospective ring geometry; P02/P03 use more explicit asymmetric structures and reverse audits. The shared function recurs, but exact form does not.

## 4. Cross-neighborhood comparison — framework plus one execution

```text
two immutable neighborhoods
→ comparison scope
→ identity tests
→ role comparison
→ edge correspondence
→ reciprocity audit
→ asymmetry / incomparability
→ Atlas readiness and disposition
```

The workflow preserved both inputs and returned negative results. It has one completed subject pair and no independent replication.

## 5. Program/meta review — recurring study discipline

```text
bounded completed corpus
→ recurrence inventory
→ template-versus-function audit
→ asymmetry and failure review
→ limitations
→ bounded disposition
```

Meta Review, Method Archaeology, Editorial Grammar, Orientation Operations, Repository Integration Review, and Orientation Cartography Reconstruction use variants of this discipline.

## 6. Comparative domain study — more than one study, heterogeneous execution

Planetary Chemistry, Morphologies of Transition, and Solar–Lunar–Carbon each:

- define a bounded comparison question;
- separate comparison objects or regions;
- qualify evidence and prohibited implications;
- publish matrices/registers and a disposition.

They do not share one fixed artifact template or prove a unified method.

## 7. Cartographic reconstruction — one audited execution

```text
completed bounded review
→ relation and boundary records
→ orientation space
→ Evidence Map
→ relation / boundary audit
→ correction
→ approved Evidence Map
→ Museum Edition
→ derivative audit and manifest
```

This is explicitly provisional. It is not a recurring program-wide workflow.

## Observed dependencies

Supported dependencies include:

- source fixation before traceable extraction;
- plural representations before cross-representation comparison;
- frozen translation before Reflection;
- completed Reflection before neighborhood admission;
- immutable inputs before cross-neighborhood correspondence;
- completed review before audited evidence mapping;
- approved Evidence Map before its Museum derivative.

The repository does not establish that every program artifact must pass through all of these phases.
