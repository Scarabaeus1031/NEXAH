## Modified-rule analysis

- **P02 status vocabulary:** “source-supported relation” was introduced as a scoped subtype without changing authority. The modification was local, but shows that the status scheme is not yet proven stable.
- **P02 freeze discipline:** Translation core and later capstone report needed distinct freeze semantics. This improved traceability but reduces simple directory-level comparability.
- **P03 representation dimensions:** phase versus state was separated because the source made their collapse misleading. This is a methodological clarification prompted by the case, not a new universal category.

None of these modifications retroactively changes P01 or another frozen artifact.
