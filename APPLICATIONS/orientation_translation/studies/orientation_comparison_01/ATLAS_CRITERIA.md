# Atlas Criteria

An Orientation Atlas is not a larger graph. It is a governed comparison environment in which multiple independent Orientation Neighborhoods remain individually inspectable while reviewed correspondences and differences become navigable.

This document defines eligibility for a future Atlas comparison. It does not construct or authorize an Atlas.

## Minimum neighborhood prerequisites

Each candidate neighborhood must have:

1. immutable identity and version;
2. fixed source boundary and provenance;
3. inspectable node and directional edge records;
4. explicit support classes and uncertainties;
5. preserved rejections and editorial bridges;
6. declared stopping rationale and reopen conditions;
7. no unresolved source or boundary mutation;
8. independent construction provenance.

## Minimum pairwise prerequisites

Before two neighborhoods may participate together, a comparison must provide:

1. an explicit orientation question for the comparison;
2. eligible comparison objects in both neighborhoods;
3. reviewed identity results without node merging;
4. separate direction and reciprocity tests;
5. preserved support inequalities;
6. explicit scale and scope alignment or incomparability;
7. recorded symmetrical and asymmetrical findings;
8. comparison failure-mode review;
9. uncertainty and unresolved correspondence records;
10. human editorial approval of the comparison record.

## Insufficient evidence

The following can nominate a comparison candidate but can never establish Atlas eligibility:

- shared vocabulary;
- shared diagrams;
- visual similarity;
- same node count;
- same edge count;
- same topology;
- matching colors, icons, or layouts;
- one reciprocal-looking line;
- common source domain;
- copied templates;
- general thematic affinity.

## Atlas admission outcomes

| Outcome | Meaning |
|---|---|
| `eligible_for_review` | Prerequisites exist; human review may begin. |
| `conditionally_eligible` | Comparison is useful but named uncertainties remain. |
| `not_yet_eligible` | Missing records or unresolved boundaries prevent admission. |
| `incompatible_for_current_question` | Both neighborhoods are valid, but the proposed comparison is not. |
| `rejected` | Admission would violate independence or evidence boundaries. |

No outcome creates an Atlas. Atlas construction would require a separate, explicitly authorized phase.
