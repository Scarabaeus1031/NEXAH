# Orientation Comparison Framework

This study designs the comparison discipline required before independently constructed Orientation Neighborhoods may be compared or considered for participation in an Orientation Atlas.

It does not perform a comparison, construct a second pilot, build an Atlas, introduce an ontology, or change any existing artifact. Its central question is:

> How can two Orientation Neighborhoods be compared without destroying their independent evidence boundaries?

The governing principle is simple: **similarity is never assumed; it must be demonstrated. Difference remains inspectable.**

## Authority boundary

This framework is a non-canonical editorial research artifact. It does not modify OLS, Registry, Kernel, architecture, existing pilots, existing neighborhoods, or OH-001. A future comparison must supply its own independently frozen evidence.
