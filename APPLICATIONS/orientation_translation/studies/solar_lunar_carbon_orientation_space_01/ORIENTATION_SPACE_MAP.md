# Orientation Space Map

## Reading rule

This map uses different line types because adjacency is not evidence identity.

```text
──▶  supported relation in the reviewed corpus
··▶  moderate or indirect relation
- -▶ weak relation proposed by prior editorial evidence
 ?▶  unknown or unsupported transition
```

## Structural interpretation

The map contains one strongly supported process route, several indirect scale transitions, one weak lunar forcing case, and multiple explicit non-edges. It is coherent as an orientation space because the reader can see where relations change status. It is not coherent as one mechanism.
