## Integration rule

References should expose the existence, scope, disposition, and non-canonical status of each study. They should not summarize findings in a way that upgrades them into repository claims.

## Navigation rule

Global navigation should point to the Orientation Translation program. The program-level index should point to individual studies. Individual studies remain the authoritative source for their own conclusions and boundaries.
