# Process Reconstruction

## Reconstruction method

The sequence below is reconstructed from timestamps implicit in artifact production and, more importantly, from explicit dependencies among `P`, `R`, and `N`. It describes what occurred; it does not claim that the order is universally necessary.

## Stage 0 — Source fixation

| Field | Reconstruction |
| --- | --- |
| Input | English Wikipedia article “Photosynthesis” and the OLS-guided pilot brief |
| Transformation | Record title, canonical URL, permanent revision, revision timestamp, SHA-1, access date, source status, license, and visible limitations |
| Output | `P/SOURCE_RECORD.md`; a fixed evidence body for all later pilot claims |
| Decision points | Which source to use; which revision to freeze; whether additional scientific sources would enter |
| Constraints | Wikipedia not normative; no silent source drift; no independent validation claim; no additional biological sources |
| New information introduced | Source identity and access metadata; declared status of the evidence body |
| Explicitly not introduced | Corrections, external scientific validation, source authority, or scientific completeness |
| Status | Source-supported observation plus editorial source-selection procedure |

## Stage 1 — Orientation Translation

| Field | Reconstruction |
| --- | --- |
| Input | Fixed source record, article observations, declared student context, OLS-guided sequence |
| Transformation | OBSERVE source material; REPRESENT it through eight separated lenses; COMPARE lenses; ORIENT through three non-ranked paths; EXPLAIN in Reader and Explain modes |
| Output | Twelve-file pilot containing observations, bounded representation, comparison, paths, renditions, evaluation, and traceability |
| Decision points | Reader context; lens set; comparison bases; three path groupings; whether SELECT was invoked; language depth |
| Constraints | Preserve source/observation, representation/reality, comparison/causality, orientation/recommendation, path/optimality, explanation/proof boundaries |
| New information introduced | Editorial lenses, reader position, path order, prerequisites, expected gains, alternative routes, explicit local boundaries |
| Explicitly not introduced | New Photosynthesis science, path recommendation, measured learning, OLS conformance, or semantic authority |
| Status | Mix of source-supported observations, process products, and declared editorial procedures |

## Stage 2 — Reflection

| Field | Reconstruction |
| --- | --- |
| Input | Frozen pilot and its own source/support declarations |
| Transformation | Compare what came from the source with what became visible through orientation; inspect cross-scale relations; list hidden questions; classify candidate bridges; assess question affordance |
| Output | `R`, including four-way status inventory, evidence gradients, hidden questions, bridge classifications, and a Pilot 02 ranking |
| Decision points | What counts as emergent; how to separate process observation from editorial construction; when a relation becomes only indirect or unsupported |
| Constraints | Do not improve pilot; do not answer hidden questions; do not create science; preserve unsupported intuitions |
| New information introduced | Findings about the architecture of the article representation, uneven support across routes, and gaps exposed by scale transitions |
| Explicitly not introduced | Answers to hidden questions, reader-effect evidence, a new concept, or an atlas claim |
| Status | Primarily process observation; bridge ranking remains editorial analysis |

## Stage 3 — Neighborhood Construction

| Field | Reconstruction |
| --- | --- |
| Input | Frozen `P` and `R`; directly or indirectly recorded local relations |
| Transformation | Admit fifteen immediate neighbors; add one secondary neighbor per first-ring node; assign role and support class to every edge; record editorial bridges and unsupported expansions separately; stop at ring two |
| Output | `N`: 31 nodes, 30 admitted edges, four excluded editorial bridges, five rejected unsupported expansions, and an explicit stopping boundary |
| Decision points | Operational meaning of “every neighbor”; inclusion threshold; secondary-depth rule; treatment of Carbon Cycle; graph inclusion versus review-only recording |
| Constraints | No automatic link admission, synonymy, transitivity, reciprocity, visual authority, or expansion beyond the frozen evidence body |
| New information introduced | Local topology, edge IDs, role classes, admission/exclusion decisions, graph size, stopping rationale, and atlas-seed assessment |
| Explicitly not introduced | Ontology, automatic graph, transitive edges, reciprocal support, completed atlas, or new source claims |
| Status | Process observations plus strong editorial procedures; possible growth rules remain candidates only |

## Dependency chain

```text
fixed source identity
        ↓ enables
bounded orientation translation
        ↓ becomes input to
reflection on representation and support
        ↓ supplies admission questions for
bounded neighborhood construction
        ↓ produces
new questions requiring a new independent source audit
```

The chain grew by changing the **object under review**: source statements → orientation products → relations among products → local adjacency. It did not grow by silently adding scientific claims.

## Reconstructed control points

1. Freeze before interpreting.
2. Declare what the representation adds.
3. Reflect before expanding.
4. Admit edges individually.
5. Record rejected possibilities.
6. Stop before the evidence body changes.

Items 1–5 are visibly used in this case. Item 6 is partly an explicit procedure and partly a candidate generalization; another case must test it.
