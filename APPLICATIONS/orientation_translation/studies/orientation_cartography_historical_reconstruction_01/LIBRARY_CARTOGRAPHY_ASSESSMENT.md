# Library Cartography Assessment

## Proposition

“Many NEXAH books may already function as orientation maps” is plausible but only partly demonstrated by repository evidence. The repository contains strong metadata, reader reviews, sequences, descriptions, and selected visuals; it does not contain a complete page-level corpus of every Are.na Work.

## Four levels

### A. A book containing maps — supported

Atlas records, visual books, whiteboards, and cartographic Works are explicitly present. `THE LANGUAGE ATLAS`, `FIELD ATLAS I — WATER`, `THE ATLAS OF ATLASES`, and `THE CARTOGRAPHY LABORATORY` have roles compatible with maps or map-making. This establishes contained cartographic material, not whole-Work cartographic behavior.

### B. A book functioning as a map — partially supported

Reader reviews describe Works whose sequence, transitions, visual plates, and continuation cues orient movement rather than merely transmit chapters. The claim is strongest for atlas/guide/handbook forms and for Works examined in representation-cycle reviews. Full admission requires page-level reconstruction of entry, alternatives, boundaries, return, and reader agency.

### C. A library functioning as an atlas — supported as an editorial architecture

The Library has stable Works, Series, reader journeys, alternate entry paths, visual/reference/practice functions, and explicit cross-Work orientation. It offers multiple views into a shared body without requiring one sequence. This is atlas-like at the curated architecture level. It is not evidence that all Works share one conceptual territory.

### D. A corpus functioning as an orientation environment — plausible, not yet demonstrated end to end

Books, Are.na channels, Registry records, studies, maps, repository navigation, and reader policies collectively support orientation. However, public traversability is incomplete, several Works remain proposals, page-level content is unevenly represented, and the interface across sources still depends on human editorial work.

## Conclusion

The Library has a defensible atlas architecture. Some Works likely function as maps, but that classification must remain Work-specific. The larger corpus is an emerging orientation environment, not a completed universal map.
