## Rejected or adjacent artifacts

| Class | Examples | Reason |
|---|---|---|
| Linear process diagrams | repository pipelines, execution flows | A fixed chain explains sequence but offers no meaningful alternative position or route. |
| Dashboards/status sheets | capability and release summaries | They report state; they do not create a navigable relational space. |
| Isolated scientific figures | Lorenz/Rössler plots, field reconstruction outputs | They represent a phenomenon but do not orient among representations. |
| Tables and inventories | registry tables, ordinary contents lists | Organization alone is insufficient. |
| Vision collages | unimplemented future-system posters | Useful proposals, but cannot establish historical practice as implemented or reviewed. |
| Uninspectable placeholder | `ARCHITECTURE/archive/gate_geometry_navigation_v4.png` | Repository object is an empty CRLF text placeholder despite its `.png` name; no visual-function claim is admissible. |
| Decorative/title imagery | covers, logos, atmospheric plates | Symbolic or aesthetic function without routing, bounding, or relational navigation. |
