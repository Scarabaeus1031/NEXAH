# Action Sequence Register

## Pilot 01 — Photosynthesis

- **Prescribed order:** fixed source → OBSERVE → REPRESENT → COMPARE → ORIENT → EXPLAIN → evaluate/trace/report.
- **Observed publication order:** twelve Translation artifacts, later Reflection, later Neighborhood.
- **Retrospective reconstruction:** Growth Study identifies source fixation, translation, reflection, and neighborhood construction as changing objects of review.
- **Loops/revisits:** Reflection revisits support and scale after Translation; Neighborhood reuses Reflection questions for admission/rejection.
- **Invisible action:** selection of eight lenses and three routes is declared but its drafting iterations are not preserved.
- **Local feature:** ring topology and one secondary neighbor per immediate neighbor shape the stop.

## Pilot 02 — Cellular Respiration

- **Prescribed order:** source fixation and source representation → observation → six representations → local comparison → four routes → Reader/Explain → evaluation/trace/report → Reflection → Neighborhood.
- **Observed execution:** Translation core was frozen before Reflection; Neighborhood followed the Reflection; capstone freeze semantics were clarified retrospectively.
- **Loops/revisits:** ATP and branch distinctions are revisited across observation, comparison, routes, and edge rejection.
- **Introduced actions:** explicit source-representation artifact, full reverse-status audit, candidate-rule result register.
- **Local feature:** asymmetric branch/process structure replaces ring geometry.

## Pilot 03 — Mitosis

- **Prescribed/observed order:** fixed source → source representation → observation → seven representations → local comparison → five routes → Reader/Explain → evaluation/trace/report → Reflection → Neighborhood.
- **Loops/revisits:** phase, state, space, condition, and outcome distinctions recur at increasing granularity; causal language is repeatedly constrained.
- **Introduced/expanded actions:** explicit phase-versus-state separation, 15-rule audit, complete reverse-status summary, explicit failure-pressure table.
- **Invisible action:** how candidate chromosome-state groupings were iterated before publication is not recorded.

## Comparison 01

- **Prescribed order:** freeze/hash both full sequences → inventory objects → test identity → compare roles/representations → test edge correspondence → audit reciprocity → record asymmetry/incomparability → evaluate Atlas criteria/failures → report.
- **Observed execution:** the 15 output artifacts follow this dependency discipline; no local graph is mutated.
- **Loops/revisits:** failed identity or edge matches return as no-match, partial, asymmetric, or incomparable records rather than repair requests.
- **Local feature:** this is comparison-only and cannot be projected backward onto pilot construction.

## Meta Review 01

- **Observed order:** hash 89-file baseline → register pilot structures → separate recurrence/template/asymmetry → audit artifact behavior and rules → collect unresolved questions → issue provisional characterization/disposition → re-hash.
- **Loops/revisits:** failure audit checks the synthesis and requires correction if a boundary is crossed.
- **Local feature:** recurrence classification is a meta-evaluation action, not part of each pilot.

## Cross-sequence observations

### Consistently early

Source fixation, limitation recording, and observation precede published representation sets.

### Consistently late

Evaluation, traceability closure, Reflection, neighborhood stopping, and capstone dispositions appear after representation and route construction.

### Actions that moved or became explicit later

Source Representation, reverse-direction audit, Process Rule audit, and Failure Pressure audit become more explicit after Pilot 01. Freeze semantics move between core and capstone reporting in P02.

### Candidate delayed-synthesis pattern

The executed artifacts visibly separate observations and multiple representations before publishing route-level and report-level synthesis. Reflection and Neighborhood then revisit the bounded package. However, this ordering is also prescribed by the shared OLS-guided template, and unpublished drafting iterations are unknown.

Status: **partly supported but template-dependent**.

The corpus supports delayed published synthesis, not a universal cognitive sequence or necessary workflow.
