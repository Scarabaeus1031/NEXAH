# Orientation Map

Four non-ranked paths are offered. They are editorial routes through the same fixed evidence body.

## Path A — Follow the transfer

- **Reader question:** How does chemical potential move toward usable ATP?
- **Starting representation:** Electron transfer
- **Sequence:** biological fuels → carrier production in pathway stages → electron transport → proton gradient → ATP synthase → ATP
- **Prerequisites:** basic molecule, electron, and membrane vocabulary
- **Expected orientation gain:** distinguish electron transfer from ATP formation
- **Limitations:** compresses carrier diversity and organism differences
- **Alternative route:** Path B for location or Path D for quantitative uncertainty
- **Unsupported implications:** no claim that all respiration uses the identical chain; no validated efficiency
- **Status:** Editorial procedure grounded in lead, pathway, and oxidative phosphorylation sections

## Path B — Locate each operation

- **Reader question:** Where does each represented transformation occur?
- **Starting representation:** Spatial organization
- **Sequence:** cytosol/glycolysis → pyruvate movement in the eukaryotic account → mitochondrial matrix/pyruvate oxidation and citric acid cycle → inner membrane/electron transport and ATP synthase
- **Prerequisites:** cell, cytosol, mitochondrion, and membrane
- **Expected orientation gain:** connect location with stage without identifying one as the other
- **Limitations:** primarily follows the source's eukaryotic emphasis; prokaryotic placement is less developed
- **Alternative route:** Path A for transfer or Path C for branching
- **Unsupported implications:** no universal mitochondrial requirement; no complete organelle model
- **Status:** Editorial procedure grounded in the aerobic subsections

## Path C — Separate the branches

- **Reader question:** What changes when oxygen, another acceptor, or no external acceptor is involved?
- **Starting representation:** Conditional branching
- **Sequence:** shared glycolysis context → aerobic respiration with oxygen → anaerobic respiration with other inorganic acceptors → fermentation without an external acceptor
- **Prerequisites:** electron acceptor and pyruvate
- **Expected orientation gain:** avoid collapsing all oxygen-independent routes into one category
- **Limitations:** source coverage is asymmetric and fermentation receives more organismal examples than anaerobic respiration
- **Alternative route:** Path B for compartment detail
- **Unsupported implications:** no equivalence, ranking, evolutionary history, or environmental prediction
- **Status:** Editorial procedure grounded in lead, fermentation, and anaerobic sections

## Path D — Audit the ATP number

- **Reader question:** Why does the source present several ATP yields?
- **Starting representation:** Yield boundary
- **Sequence:** gross pathway accounting → substrate-level versus oxidative phosphorylation → transport costs → proton leak and uncoupling → shuttle and organism-specific details → unresolved range
- **Prerequisites:** ATP, NADH/FADH2, proton gradient
- **Expected orientation gain:** read ATP totals as bounded representations with assumptions
- **Limitations:** the pilot does not adjudicate the figures or cited research
- **Alternative route:** Path A for mechanism before accounting
- **Unsupported implications:** no selected correct yield; no universal efficiency claim
- **Status:** Editorial procedure grounded in Aerobic respiration and Efficiency sections

## Path boundary

No path is best, complete, or recommended. A reader may start from a question, switch routes, or stop. Expected gains are editorial hypotheses, not measured outcomes.
