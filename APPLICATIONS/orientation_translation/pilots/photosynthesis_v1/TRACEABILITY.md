- no external publication or write to Wikipedia;
- no independent scientific fact-check beyond recording source language and status.

## Reproduction note

Recheck the permanent Wikipedia revision, confirm revision ID/timestamp/SHA-1, then compare each observation and path basis with the named source sections. Later source changes do not silently alter this pilot because its source identity is fixed.
