# Explain Mode

The fixed source presents Mitosis as the separation of an already replicated chromosome set into daughter nuclei. Before Mitosis, chromosome duplication has occurred during S phase. When the mitotic account begins, chromatin condenses, spindle structures form, and chromosome descriptions shift from replicated chromosomes and sister chromatids toward separated daughter chromosomes.

The familiar phase names provide landmarks, but they do not each name one event. During Prophase, condensation and spindle formation are described together. In open Mitosis, Prometaphase includes nuclear-envelope disassembly and access of microtubules to kinetochore structures; the same boundary account does not apply unchanged to closed Mitosis. Attachment and tension help locate chromosomes around the metaphase plate. The source then places checkpoint language at the boundary to Anaphase, but a condition for proceeding is not an assurance that every later event succeeds.

During Anaphase, cohesin cleavage, chromosome naming, microtubule shortening, movement toward opposite sides, and cell elongation appear as related but distinct operations. Their source order does not automatically make every adjacent pair a direct causal relation. Telophase reconstructs nuclear boundaries where those boundaries had broken down, and chromosome sets decondense within daughter nuclei.

Cytokinesis introduces another boundary. It divides cellular material and may overlap mitotic progression, yet the source calls it a separate process and records cases where Mitosis occurs without Cytokinesis. The standard route therefore ends in a represented result rather than a guaranteed universal cycle. Variations in nuclear-envelope behavior, spindle form, separation, chromosome complement, and cell outcome remain visible beside the conventional sequence.

## Explain Mode audit

Reader Mode exposes entry points and distinctions; Explain Mode connects them into continuous prose. That continuity introduces risk:

| Risk | Safeguard |
|---|---|
| apparent causality from prose order | predicates remain local and source-linked |
| smoothed phase boundaries | multiple operations inside each phase are named |
| hidden organismal exceptions | open/closed forms and plant/animal differences remain visible |
| compressed spatial differences | nucleus, plate, poles, and cellular boundary stay distinct |
| conditions turned into guarantees | checkpoint language is explicitly bounded |
| one correct route implied | five alternative Reader Paths remain authoritative |

Explain Mode is a rendition of the Orientation Model, not additional evidence.
