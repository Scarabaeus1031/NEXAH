# Orientation Map

The map offers five non-ranked reader paths. A reader path is an editorial route through representations, not a biological pathway or graph edge.

## Path A — Follow the named landmarks

- **Question:** In what order does the source present Mitosis?
- **Entry:** M-REP-01 Phase landmarks
- **Route:** Phase landmarks → Process boundary → Result and wider function
- **Transitions:** locate sequence; check what is inside/outside Mitosis; stop at represented result
- **Stop:** daughter nuclei and the optional/separate Cytokinesis boundary
- **Clarifies:** the conventional progression without treating Cytokinesis as a mitotic phase
- **Does not establish:** that adjacency is causality, that every organism uses the same phase geometry, or that completion is guaranteed

## Path B — Track chromosome continuity

- **Question:** What happens to the represented chromosome set?
- **Entry:** M-REP-02 Chromosome continuity and state
- **Route:** replicated chromosome/sister chromatids → condensation → alignment → separation/daughter chromosomes → decondensation/daughter nuclei
- **Transitions:** track changing names, grouping, position, and boundary
- **Stop:** two represented chromosome sets enclosed as daughter nuclei
- **Clarifies:** why a phase list is insufficient for following identity language
- **Does not establish:** a complete molecular inheritance theory or error-free identity

## Path C — Locate the reorganization

- **Question:** Where do structures and boundaries change?
- **Entry:** M-REP-03 Spatial reorganization
- **Route:** nucleus/centrosome context → spindle and kinetochore attachment → metaphase plate → opposite poles → nuclear-envelope reformation
- **Transitions:** locate movement, attachment, alignment, and boundary change
- **Stop:** reformed daughter nuclei; optionally branch to Cytokinesis location
- **Clarifies:** simultaneous spatial work hidden by a linear phase summary
- **Does not establish:** one universal open-mitosis geometry or organelle equivalence

## Path D — Audit continuation and deviation

- **Question:** What permits progression, and where can the represented outcome differ?
- **Entry:** M-REP-04 Attachment and continuation conditions
- **Route:** attachment/alignment → checkpoint statement → anaphase permission → M-REP-06 variation/error outcomes
- **Transitions:** distinguish condition, cue, event, and outcome
- **Stop:** at the source’s named deviations or at its missing control mechanism
- **Clarifies:** checkpoint passage is not a guarantee and normal sequence is not the only represented outcome
- **Does not establish:** a complete checkpoint network, error probability, disease prognosis, or intervention

## Path E — Separate neighboring processes

- **Question:** What is Mitosis, and what is only before, after, or alongside it?
- **Entry:** M-REP-05 Process boundary
- **Route:** Interphase prerequisite → nuclear division/Mitosis → Telophase completion → Cytokinesis as separate and sometimes absent
- **Transitions:** mark prerequisite, membership, adjacency, and independence with different relations
- **Stop:** once nuclear division and cell division are no longer conflated
- **Clarifies:** the boundary between phase, process, nucleus, and cell
- **Does not establish:** a full Cell Cycle model or a closed universal cycle

## Map boundary

No route is optimal or complete. Readers may switch paths where the source provides traceable overlap. Expected clarification is an editorial proposition; actual reader benefit is untested.
