# Source Representation

This file describes how revision `1359310650` represents Mitosis before orientation is added.

## Documentary organization

The article opens with a compressed definition and outcome, then places Mitosis inside the cell cycle, gives an ordered phase account, separates Cytokinesis, broadens to function, variations, errors, diagnostics, related processes, and evolution. Narrative order is therefore not identical to biological order.

## Distinctions the source requires

- An article section is not a biological phase.
- A phase name is not a single cell state; each phase contains several events and structures.
- Temporal order is not automatically causality.
- Spatial containment and spatial movement are different relations.
- Checkpoint language describes conditions/cues, not certain success.
- Mitosis and Cytokinesis can be temporally coordinated yet remain distinct processes.
- A daughter nucleus is not identical to a daughter cell.
- Open, closed, and semi-open mitosis prevent one nuclear-envelope narrative from becoming universal.
- Normal result language does not eliminate documented errors and variants.

## Source limitations for orientation

The source is detailed but heterogeneous. It does not provide one uniform causal model, consistent granularity across phases, complete checkpoint logic, complete molecular depth, or a single organism-independent spatial account. Illustrations help recognize stages but may make adjacency appear more deterministic than the prose supports.
