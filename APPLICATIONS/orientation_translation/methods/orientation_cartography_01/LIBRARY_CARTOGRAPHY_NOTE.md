# Library Cartography Note

## Working proposition

Many NEXAH books may already function as orientation maps. The historical review supports this only at different confidence levels.

### A. A book containing maps

Supported. Atlas, guide, handbook, laboratory, and whiteboard Works contain or explicitly promise visual/spatial representations. This says nothing about the book's whole structure.

### B. A book functioning as a map

Partially supported. A Work qualifies only when its sequence, alternatives, transitions, boundaries, and returns create a navigable orientation structure. Title, visual density, plates, or a table of contents are insufficient. Page-level review is still required for each Work.

### C. A library functioning as an atlas

Supported as an editorial architecture. The Library provides multiple Works, Series, functions, reader journeys, and entry paths into a shared corpus. It preserves different views rather than demanding one sequence. It must not imply that all Works share one theory or evidence base.

### D. A corpus functioning as an orientation environment

Plausible, not yet demonstrated end to end. Are.na, repository records, studies, maps, reader policies, and public paths can jointly support navigation. Uneven page access, proposal status, incomplete public links, and reliance on human curation remain material limits.

## Boundary

Orientation Cartography is not a new classification imposed on the Library. It is a provisional lens for asking which Works and relations actually support navigation. Registry, entity type, Work identity, and canonical metadata remain unchanged.
