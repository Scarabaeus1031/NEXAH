# Failure Modes

| Failure | Distortion | Control |
|---|---|---|
| Map mistaken for territory | representation treated as reality | state scope and non-claims |
| Visual balance replacing evidence asymmetry | weak regions appear equally supported | preserve unequal connection and prominence |
| Proximity mistaken for causality | neighboring labels imply mechanism | crosswalk placement reason and relation type |
| Landmass size mistaken for quantitative importance | area becomes an undeclared metric | state qualitative design role |
| Route mistaken for mechanism | reading order becomes causal order | label reader/editorial routes |
| Mountain range mistaken for inevitability | strong path appears necessary or universal | record scope, variants, and branch limits |
| Island mistaken for irrelevance | weakly connected region appears unimportant | explain that isolation represents current support |
| Unexplored territory aestheticizing missing evidence | uncertainty becomes decorative mystery | attach named questions and source gaps |
| Inconsistent line styles | support classes become unreadable | audit every edge against legend |
| Physical scale accidentally introduced | conceptual distance appears measurable | use `RELATIONAL DISTANCE IS QUALITATIVE` |
| Decorative bridges implying admitted relations | visual continuity creates a false edge | audit non-edges and connective motifs |
| Intermediate removed for simplicity | transition skips a required relation | compare every route with source matrix |
| Book sequence retrospectively misclassified as formal map | narrative order is overclaimed | require multiple cartographic functions and reader movement |
| Historical continuity overstated | later method projected onto earlier artifacts | preserve original purpose and date |
| Public edition drifts from Evidence Map | atmosphere changes meaning | maintain relation crosswalk and derivative audit |
| Open region silently completed | unknown becomes assertion | fail closed and retain blank/open status |
