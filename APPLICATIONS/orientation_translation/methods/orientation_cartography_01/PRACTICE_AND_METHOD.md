# Practice and Method

## Orientation Cartography as practice

Historically recurring ways of constructing orientation through books, maps, plates, sequences, neighborhoods, layers, and visual fields. Recurrence is established by function across multiple artifacts; it does not imply a shared production procedure.

Typical functions include locating, relating, differentiating, routing, bounding, scaling, opening questions, translating, and supporting return.

## Orientation Cartography as method

An explicit and repeatable workflow would require:

- bounded source material;
- relation extraction;
- evidence qualification;
- boundary and non-edge registration;
- visual reconstruction;
- relation and boundary audit;
- correction with recorded rationale;
- publication-layer control;
- source-to-map traceability;
- reproducibility across independent cases.

The Solar–Lunar–Carbon case demonstrates the first nine within one production. It does not yet demonstrate cross-case or independent reproducibility.
