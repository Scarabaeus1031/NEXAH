# WINDOW 04 — Three-Domain Replication Matrix

Status: `UNADMITTED_EXPLORATORY_MODEL_BENCHMARK`

This local-only extension repeats the Window 03 cylinder-versus-open comparison
over deterministic seeds and a declared chemical threshold sweep. It reports an
integrated cell-address residual fraction, peak residual, detection frequency
and mean cubical-complex `beta0` / `beta1` for three separate finite models.

The shared observer makes response profiles comparable. It does not make the
chemical, Life and spin states, operators, units, causes or mechanisms
identical. The package reuses the LIFE08/LIFE_ORBIT presentation identity and
does not create a new Navigator identity or alter the frozen LIFE08 result.
