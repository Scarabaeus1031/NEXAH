# ⚡ NEXAH Power Systems

Geometry-Based Stability Analysis and Regime Navigation
for Electrical Power Networks.

---

## Overview

This repository contains the power-system application layer of the NEXAH framework.

NEXAH interprets power systems as trajectories evolving within structured dynamical fields.

The framework focuses on:

- regime detection
- stability geometry
- trajectory analysis
- structural early warning
- experimental navigation and control
