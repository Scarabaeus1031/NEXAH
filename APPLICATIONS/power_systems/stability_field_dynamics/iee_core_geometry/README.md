# NEXAH / ieee_scaling

**Skalierungs-Tests auf großen Netzen**  
IEEE 118-Bus, IEEE 300-Bus und später reale Netze.

Verwendet die aktuelle Core-ODE v9.5 (2-1-3 Regulator + Q° Binder + Winding-Number-Trigger).

Ziel: Nachweis, dass der Mic-Drop-Effekt (Phi-Split deutlich vor Voltage-Collapse) auch auf großen Systemen stabil funktioniert.
