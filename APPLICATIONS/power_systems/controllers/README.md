# Power-System Controllers

This directory contains controller concepts and navigation logic developed within the NEXAH power-system framework.

---

## Atlas Navigation Controller V1

File:

atlas_navigation_controller_v1.py

Status:

Historical prototype.

Developed prior to the Atlas Operations phase
(EXP_29–EXP_36).

The controller operates using:

- risk
- risk slope
- residual structure
- distance to separatrix

and represents an early navigation-oriented control concept.

The controller predates:

- Basin Discovery
- Recovery Corridors
- Recovery Anchors
- Atlas-Guided Control

and is preserved as the conceptual precursor to future atlas-native controllers.
