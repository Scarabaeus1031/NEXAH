
# NEXAH Testing Framework

This folder contains all the tests for the NEXAH Framework, organized by functional area. Below is an overview of each test category. To run the tests, please refer to the instructions at the bottom.

## Stability Tests
These tests focus on the **stability analysis** of NEXAH's core systems. They validate the stability of system states, regime transitions, and the kernel's ability to maintain system balance.

- [test_stability_kernel.py](./stability_tests/test_stability_kernel.py): Validates the core kernel's stability mechanisms.
- [test_stability_regimes.py](./stability_tests/test_stability_regimes.py): Tests regime transitions and stability thresholds.
- [test_stability_analysis.py](./stability_tests/test_stability_analysis.py): Ensures correct analysis of system stability over time.

## Regime Navigation Tests
These tests evaluate how well the **regime navigation** system functions, ensuring that agents can successfully navigate from one regime to another within a system's state space.

- [test_regime_dynamics.py](./regime_navigation_tests/test_regime_dynamics.py): Tests the movement between different system regimes.
- [test_transition_mapping.py](./regime_navigation_tests/test_transition_mapping.py): Validates the mapping of system transitions.
- [test_navigation_algorithms.py](./regime_navigation_tests/test_navigation_algorithms.py): Ensures that the navigation algorithms are functioning as expected.

## Cascading Failure Tests
This category includes tests that simulate **cascading failures** in interconnected systems. These are essential for evaluating the NEXAH framework's ability to handle and prevent widespread system failures.

- [test_power_grid_failure.py](./cascading_failure_tests/test_power_grid_failure.py): Simulates power grid cascading failures.
- [test_infrastructure_cascade.py](./cascading_failure_tests/test_infrastructure_cascade.py): Tests the effects of cascading failures in infrastructure systems.
- [test_cascading_networks.py](./cascading_failure_tests/test_cascading_networks.py): Validates the simulation of cascading failures across multiple network layers.

## System Model Tests
This category contains tests for various system models used in NEXAH, including energy grids, supply chains, and planetary systems.

- [test_energy_grid_model.py](./system_model_tests/test_energy_grid_model.py): Tests the energy grid model for stability and failure simulations.
- [test_supply_chain_model.py](./system_model_tests/test_supply_chain_model.py): Validates the functionality of the supply chain model in NEXAH.
- [test_planetary_system_model.py](./system_model_tests/test_planetary_system_model.py): Ensures that the planetary system model behaves correctly under various scenarios.

## Visualization Tests
These tests ensure that all **visualizations** generated by NEXAH are accurate and render properly. They validate that system graphs, navigation paths, and cascades are represented correctly.

- [test_state_graph_visualization.py](./visualization_tests/test_state_graph_visualization.py): Tests the integrity of system state graph visualizations.
- [test_navigation_path_visual.py](./visualization_tests/test_navigation_path_visual.py): Validates the visualization of navigation paths in the regime landscape.
- [test_cascade_visualization.py](./visualization_tests/test_cascade_visualization.py): Ensures that cascade failure visualizations are accurate and clear.

---

## Running Tests

To run the tests, navigate to the `tests/` directory and execute the following:

1. Install dependencies (if not already installed):
   ```
   pip install -r requirements.txt
   ```

2. Run individual tests using `pytest`:
   ```
   pytest <test_file.py>
   ```

   Example:
   ```
   pytest stability_tests/test_stability_kernel.py
   ```

   To run all tests at once:
   ```
   pytest
   ```
