# NEXAH Testing Framework

This directory contains the full automated test suite for the **NEXAH Engine and Framework**.

The test system validates the mathematical kernel, system dynamics, navigation logic, and applied simulation layers of NEXAH.

Current test status

- ~88 automated tests
- Full coverage of the algebraic core engine
- Executed via pytest
- Structured by functional test domains

---

---

# Core Engine Tests

Folder

core_tests/

These tests validate the algebraic execution layer of the NEXAH Engine.

Covered components include

- Finite posets
- Lattice structures
- Closure operators
- Interior operators
- Monotone operators
- Frame operators
- Regime operators
- Fixpoint computation
- Worklist algorithms
- Rank structures
- Hasse diagram generation

These tests ensure the correctness of the formal mathematical kernel that all higher-level NEXAH systems depend on.

---

# Stability Tests

Folder

stability_tests/

These tests evaluate the stability properties of systems modeled within NEXAH.

They verify

- Kernel stability behavior
- Stability thresholds
- Regime persistence
- Long-term system balance

---

# Regime Navigation Tests

Folder

regime_navigation_tests/

These tests validate the navigation logic through regime landscapes.

They focus on

- Regime transitions
- Navigation algorithms
- Transition mapping
- State-space movement

The navigation layer is essential for exploring complex dynamical systems.

---

# Cascading Failure Tests

Folder

cascading_failure_tests/

These tests simulate cascading failures in interconnected systems.

Example domains

- Power grids
- Infrastructure networks
- Interdependent system failures

The goal is to evaluate how NEXAH detects and models systemic collapse propagation.

---

# System Model Tests

Folder

system_model_tests/

These tests validate domain-specific models implemented in NEXAH.

Example models include

- Energy grid simulations
- Supply chain systems
- Planetary or astrophysical models

These tests ensure that domain models integrate correctly with the NEXAH engine.

---

# Visualization Tests

Folder

visualization_tests/

These tests ensure the correctness of visual output generated by the framework.

They verify

- State graph rendering
- Navigation path visualization
- Cascade diagrams
- Structural system graphs

Visualization is a key part of the NEXAH analysis workflow.

---

# Pipeline Tests

Folder

pipeline_tests/

Pipeline tests validate complete execution chains of the framework, ensuring that multiple modules interact correctly.

They test end-to-end workflows across

- Engine computation
- Regime navigation
- System modeling
- Visualization output

---

# Running Tests

From the project root directory run

pytest

Run a specific test category

pytest tests/core_tests
pytest tests/stability_tests
pytest tests/regime_navigation_tests

Run a single test file

pytest tests/core_tests/test_lattice.py

---

# Development Guidelines

When adding new functionality to NEXAH

- Add tests in the appropriate category
- Ensure tests remain deterministic
- Keep test cases minimal and focused

All contributions should maintain or improve test coverage.

---

# Philosophy of the Test Suite

The NEXAH testing system is designed to ensure that

- The algebraic kernel remains mathematically valid
- System simulations remain stable and reproducible
- Navigation algorithms behave predictably
- Complex system models integrate correctly

The test framework therefore acts as the formal validation layer of the NEXAH architecture.
