# NEXAH Repository Map

NEXAH is not a collection of folders.

It is a **multi-layer system for discovering, mapping, and navigating structure in complex dynamics**.

This document provides a high-level orientation across the repository.

It explains:

- where the main system layers live
- what their roles are
- how research, framework, applications, and exploration connect
- where to start depending on your goal

---

## 🚀 Main Entry Point

If you are new to the repository, start here:

👉 [`START_HERE.md`](../../START_HERE.md)

This is the fastest way to:

- run one experiment
- see visible structure
- enter NEXAH without reading the full theory first

---

## 🧠 Core Idea

NEXAH studies how **structure, motion, and collapse** emerge in complex systems.

The repository is organized around a central progression:

```text
simulation → structure → field → geometry → navigation
```

This means:

- systems are simulated
- structural regularities are extracted
- flow structure becomes visible
- transition geometry is reconstructed
- navigation through stability regimes becomes possible

---

## 🌐 Main Repository Areas

The repository currently consists of several major areas.

| Directory | Role |
|------|------|
| `ENGINE/` | research engine, analysis core, experimental infrastructure |
| `FRAMEWORK/` | architectural system stack and formal NEXAH framework structure |
| `APPLICATIONS/` | domain-specific realizations and real-world use cases |
| `BUILDER_LAB/` | demos, exploratory constructions, proto-models |
| `NAVIGATOR/` | architectural overviews, repository maps, system orientation |
| `DISCOVERY_ENGINE/` | structural extraction and discovery logic |
| `RESEARCH/` *(if present as separate layer in older structure)* | legacy / parallel research material |

---

## 🧱 Architectural Stack

The current NEXAH framework is organized through the structural stack:

```text
META → ARCHY → MESO → NEXAH → MEVA
```

| Layer | Function |
|------|------|
| META | relational system definition |
| ARCHY | regime structure and simulation dynamics |
| MESO | risk geometry and collapse structure |
| NEXAH | navigation through structured fields |
| MEVA | execution and trajectory realization |

This stack is mainly documented in:

👉 [`FRAMEWORK/README.md`](../../FRAMEWORK/README.md)

## 🧪 Experimental Research Layer

Location:

```text
ENGINE/research/experiments/
```

This is one of the most important research zones in the repository.

It contains exploratory but often structurally significant modules such as:

- `prime_modular_resonance/`
- `structured_oscillator_networks/`
- `symmetry_graph_experiment/`
- `nexah_stability_driven_multi_agent_system/`

These modules investigate topics such as:

- discrete transition bias
- resonance structures
- vortex and basin formation
- synchronization and frustration
- topology-driven phase behavior
- multi-agent structure discovery

These are not merely isolated toy experiments.

They are part of the research path by which NEXAH discovered:

- structural regimes
- field-like behavior
- resonance corridors
- geometry emerging from dynamics

## 🧠 Research Documents vs Framework Documents

A useful distinction is:

### Research documents
live mainly in:

```text
ENGINE/research/
```

They are often:

- exploratory
- conceptual
- mixed in maturity
- close to discovery processes

Examples:

- `NEXAH_THEORY.md`
- `NEXAH_DYNAMICS.md`
- `NEXAH_TEMPORAL_MODEL.md`
- `NEXAH_RESULTS.md`
- `NEXAH_MATHEMATICS_INDEX.md`

### Framework documents
live mainly in:

```text
FRAMEWORK/
```

They are usually:

- more stabilized
- more architectural
- more explicitly integrated into the system stack
