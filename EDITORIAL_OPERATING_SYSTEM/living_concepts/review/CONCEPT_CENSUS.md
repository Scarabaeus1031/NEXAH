# Phase X0 — Concept Census

**Status:** proposal-only evidence review  
**Machine-readable source:** [concept_census.yaml](concept_census.yaml)

## Method

Stage A gathered terms from the approved Research, Foundation, Validation,
Discovery Engine, Operator Registry, Library classification, and stored public
source-snapshot texts. Counts are raw lexical file counts and include false
positives such as `numpy.stack`.

Stage B inspected retained candidates for an explicit NEXAH meaning,
Definition Provenance, Operator overlap, scoped claim support, ambiguity, and
reader value. Frequency never determined classification.

## Main uncertainties

- Operator definitions are concise editorial contracts; Research meanings are
  sometimes broader and sometimes scientifically narrower.
- The Research layer uses inconsistent evidence language inherited from
  multiple development periods.
- Library descriptions establish editorial intent but not scientific support.
- Work titles can resemble Concept names without defining an independent idea.
- Git history can establish an earliest reviewed repository occurrence, not an
  absolute origin across books and private notes.

No candidate in this Census is canonicalized by this review.
