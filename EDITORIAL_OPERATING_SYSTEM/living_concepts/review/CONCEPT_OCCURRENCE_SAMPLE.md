**Status:** non-canonical model test  
**Structured sample:** [concept_occurrence_sample.yaml](concept_occurrence_sample.yaml)

candidate: **15 verified Occurrences**. It tests the evidence model; it is not a
complete semantic annotation of the repository or Library.

## JANUS

1. The Operator Registry **defines** the current Janus Operator.
2. `JANUS_OPERATOR/README.md` **develops** forward/backward directional
   compatibility as an exploratory research observable.
3. the State Transition Orientation Framework **contrasts** JANUS principle,
   Janus Bridge, and Directional Coherence analysis.

Finding: broader Concept review is justified precisely because the repository
already distinguishes several scopes. The existing Operator remains
authoritative and unchanged.

## Aperture

1. the Operator Registry **defines** selective opening and framing;
2. `aperture_geometry.md` **develops** localized transition access and gate
   geometry;
3. THE LANGUAGE ATLAS description **visualizes** the pedagogical statement
   “Every map is an aperture.”

Finding: one word bridges editorial, perceptual, and scientific scopes. These
scopes require related Definitions rather than a single flattened meaning.

## Vessel

1. `vessel_geometry.md` provides a **Working Definition**;
2. the Core Concept Map **discusses** Vessel as containment and persistence;
3. the Core Concepts README **develops** its role in the research architecture.

Finding: Vessel is the strongest non-Operator dossier candidate. It has a
recognizable NEXAH-specific meaning and explicit limitations.

## Resonance

1. THE CATHEDRAL OF RESONANCE **develops** an editorial framework involving
   emergence, memory, and feedback;
2. Prime Modular Resonance **tests** discrete transition structures under a
   program carrying the term;
3. LOGARITHMIC UNIVERSE **discusses** resonance across scales as a visual
   framework.

Finding: recurrence is strong, but meanings are heterogeneous. A dossier must
separate physical analogy, mathematical program name, structural recurrence,
and editorial metaphor.

## Living Equation

1. the source snapshot verifies the Work title and description;
2. classification records propose a synthesis-atlas role;
3. Reader Review tests the Work as a research-path destination.

Finding: all three Occurrences currently refer to the Work. They do not yet
establish an independent Living Equation Concept. This negative result makes it
a valuable identity-boundary dossier.

## Model result

The Occurrence model is practical if it preserves:

```text
source + locator
occurrence role
occurrence verification
assertion origin
scoped claim support
editorial note
```

The sample also demonstrates that a verified source passage must not be
relabeled as an observed scientific outcome.
