- a numbered action palette;

### Variant cluster B

- similar exemplar descriptions;
- repeated short stacks and outcomes.

They are treated as one independent editorial Work family.

cyclicity, and a long example stack. It is counted independently.

field relation, and return structure. It is counted independently.

## Counting rationale

- repeated evidence inside a family shows editorial persistence but counts once;
- support classes are assigned by independent family, not file count;
- layout repetition is not evidence of a process;
- a caption is evidence only for the artifact in which it appears;
- cross-domain examples are treated as editorial examples, not proof of shared
  mechanisms;
- previous Reviews are excluded from primary evidence.
