# Orientation Process Review 01 — State and Transition Models

These are the smallest models supported by each independent Work family. State
labels are descriptive conveniences, not canonical entities.

## WF-A — General action grammar

### Minimal model

```text
available field
      ↓
several displayed changes
      ↓ one is explicitly chosen
changed view or relation
      ↓
newly noticed pattern / integration
      └───────────────→ possible renewed viewing
```

### Transition descriptions

- field → displayed changes: editorial presentation, not proven temporal cause;
- displayed changes → chosen change: explicit instructional narrowing;
- chosen change → changed view: represented transformation;
- changed view → pattern/integration: conceptual or editorial continuation;
- integration → renewed viewing: visible in a loop variant, not universal.

### Order

Explicit as reading/instructional order. Temporal and causal status is
uncertain.

### Reversibility and skips

Several changes are depicted as reversible; others are not. Example stacks
skip many palette entries. No full order is required.

### Branches and loops

Branching is explicit at the palette. A loop is locally explicit.

### Uncertainty

The separation between choosing, applying, and noticing may be editorial rather
than a stable process boundary.

## WF-B — Living operator library

### Minimal model

```text
actor(s) in field
      ↓
detection / relation / environmental signal
      ↕
adjustment or selected stack
      ↓
example-specific continuation
      ↓
feedback, return, refinement, or sharing
```

### Transition descriptions

- initial relation → detection: explicit in several examples;
- detection ↔ adjustment: often coupled rather than strictly ordered;
- stack → continuation: editorially explicit, mechanism-specific only locally;
- continuation → feedback: explicit in trails, memory, adaptation, and refine
  language.

### Order

Mixed. The build panel is ordered; natural examples may be simultaneous,
conditional, or environmentally driven.

### Reversibility and skips

Return and adaptation imply revisability. Target lock and commitment may not be
reversible within the depicted sequence. Each example skips most functions.

### Branches and loops

The palette permits branches; natural examples often show one route. Feedback
loops are local but recurrent.

### Uncertainty

It is unclear where editorial selection ends and depicted organism or group
behavior begins.

## WF-C — Paired and cyclic synthesis

### Minimal model

```text
referenced configuration
      ↓
one editorially displayed chain of changes
      ↓
return / alignment / balanced relation
      ↺
```

### Transition descriptions

- configuration → chain: explicit visual reading order;
- chain → return/alignment: explicit in the example stack;
- return → next cycle: structurally implied, not operationally described.

### Order

Explicit as an example sequence, but not established as temporal, causal, or
mandatory.

### Reversibility and skips

Counter-direction, reflection, and return imply local reversibility. The Work
does not establish whether the full chain reverses or which stages may be
skipped.

### Branches and loops

The palette implies alternative compositions. The wheel and return depict a
loop. No branch-selection event is shown.

### Uncertainty

The apparent middle process may be a curated demonstration rather than a
depicted decision process.

## WF-D — Reciprocal relational case

### Minimal model

```text
participant A ↔ shared field ↔ participant B
      ↕          ↕           ↕
movement ↔ response ↔ mutual adjustment
      ↓
shared pattern / release
      ↓
changed encounter
      └──────────↺
```

### Transition descriptions

- detection, movement, response, and adjustment alter one another continuously;
- a shared pattern emerges from coupling, not from a visible isolated choice;
- release changes the next encounter and begins another cycle.

### Order

Numbered stages provide a readable sequence, but the central relation is
simultaneous and reciprocal. A strict temporal chain is contradicted by the
depicted coupling.

### Reversibility and skips

Role exchange and return are reversible in principle. The Work does not show
that stages can be freely skipped.

### Branches and loops

An open field of trajectories is explicit; discrete branches are not. The
feedback loop is explicit.

### Uncertainty

No stable boundary separates encounter, adjustment, and continuation.

## Cross-family state finding

All four families distinguish an initial condition from at least one changed
condition. Three depict a readable middle region with displayed changes or a
curated chain. The fourth depicts continuous coupling in which the middle
cannot be cleanly separated. This supports recurrence of an intermediate
process while contradicting one fixed layer boundary.
