# Orientation Language Specification 1.0 — Publication Summary

`OLS-RELEASE-1.0.0` is the first complete canonical publication of the Orientation Language Specification.

The publication contains exactly eight specification documents: seven normative parts and one informative companion. Together they cover suite conventions, the Universal Base Language, declarations and primitive operator contracts, semantic profiles, derivations and transitions, conformance and testing, governance and versioning, and informative guidance.
