# Phase as Structural Coordinate

## Definition

θ(t) = atan2(y(t), x(t))

## Properties

- continuous (mod 2π)
- unwrappable → θ_unwrapped(t)
- defines ordering along trajectory

## Derived quantities

Δθ(t) = θ(t+1) - θ(t)

w(t) = θ_unwrapped(t) / 2π

## Interpretation

Phase is not a physical observable,
but a coordinate induced by projection.

It acts as:

→ local coordinate
→ transport direction
→ ordering mechanism
