# Phase Drift

## Definition

Δθ(t) = θ(t+1) - θ(t)

## Statistics

μ_Δθ = E[Δθ]
σ²_Δθ = Var(Δθ)

## Observations

- Δθ is not symmetric
- drift persists over time
- induces directional transport

## Interpretation

Non-zero mean drift implies:

→ broken symmetry
→ preferred direction in phase space
→ transport across structure

## Key Result

Drift transforms phase into a transport coordinate.
