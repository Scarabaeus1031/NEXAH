# 🔁 3. Phase Velocity

Temporal phase evolution:

```math
\omega(t)
=
\frac{d\phi(t)}{dt}
```

Discrete approximation:

```math
\omega(t)
\approx
\frac{
\phi(t+\Delta t)-\phi(t)

\Delta t
}
```
