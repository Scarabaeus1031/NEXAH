## The missing four-component connector

Let the trinomial Pascal carrier use nonnegative coordinates `(a,b,c)` and

```text
n = a+b+c.
```

Introduce the explicit affine embedding

```text
Phi(a,b,c) = n*1 + a*i + b*j + c*k.
```

This places every Pascal node in the standard four-real-component quaternion
space while keeping the scalar component dependent on the Pascal layer:

```text
scalar(Phi) = n = a+b+c.
```

The interpretation is typed:

- `1` carries the layer/record coordinate `n`;
- `i,j,k` carry the three trinomial directions;
- `Q°` selects or changes the reading operator;
- `Q°` is not a fifth quaternion component.

Thus the four quaternion basis channels become visible without pretending
that the Pascal carrier itself is quaternion algebra.

## Exact C3 action

Use the unit quaternion

```text
u = (1+i+j+k)/2.
```

Conjugation by `u` performs a 120-degree rotation around `(1,1,1)` and cycles
the three imaginary basis directions. Consequently

```text
Phi(a,b,c) -> u Phi(a,b,c) u^-1
```

fixes the scalar layer `n`, cycles `(a,b,c)`, and preserves:

- integer lattice membership;
- multinomial weights;
- parent-to-child recurrence edges;
- the layer sum `3^n`.

This recovers exactly the already tested proper subgroup `C3`. Reflections
complete the carrier's `S3` symmetry but are not quaternion rotations in
`SO(3)`. Generic unit-quaternion rotations remain valid view operators and
fail the discrete Pascal-lattice automorphism test as expected.

## Four-to-five architecture

The previously introduced lift

```text
Lambda(2,3) = (2^2,2+3) = (4,5)
```

now has a bounded architectural reading:

```text
4 = |{1,i,j,k}|                    quaternion basis slots
5 = |{1,i,j,k} union {Q°}|         four slots plus controller
```

This does not define a five-dimensional quaternion. It distinguishes two
typed grids:

- `4^2=16`: the sixteen ordered products of the quaternion basis table;
- `5^2=25`: the twenty-five ordered positions of a controller-augmented
  relation grid, not a quaternion multiplication table.

The prime-index readout `p_16=53`, `p_25=97` may be displayed in a separate
coordinate lane. It is not generated by quaternion multiplication.

## Two different return operators

The HTML must keep two returns visibly separate.

### Quaternion view return

For a unit quaternion `u`:

```text
R_u(x) = u*x*u^-1
R_u^-1(R_u(x)) = x.
```

This tests reversible orientation transport.

### Scalar Record/Play return

For nonzero scalar readout `x`:

```text
Q_432(x) = 432/x
Q_432(Q_432(x)) = x.
```

This tests the separate Record/Play register. Shared return grammar does not
make `R_u` and `Q_432` the same operator.
