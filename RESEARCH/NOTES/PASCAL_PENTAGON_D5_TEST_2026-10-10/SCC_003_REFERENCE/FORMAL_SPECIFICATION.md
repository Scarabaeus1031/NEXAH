This document defines the finite object independently of its HTML view and

## 1. One Pascal carrier `P_6`

Let

```text
T_6 = {(n,k) in Z^2 : 0 <= k <= n <= 6}.
```

The depth-six Pascal carrier is the directed weighted graph

```text
P_6 = (T_6, E_6, w_6)
```

with

```text
E_6 = {
  ((n,k),(n+1,k)),
  ((n,k),(n+1,k+1))
  : 0 <= k <= n < 6
}

w_6(n,k) = binom(n,k).
```

Its left side is `L={(n,0):0<=n<=6}`, its right side is
`R={(n,n):0<=n<=6}`, and its apex is `(0,0)`. It has `28` vertices and `42`
directed edge incidences.

The carrier is regarded simultaneously as:

1. a macro-triangular face used for gluing; and
2. an internal directed recurrence graph.

The macro-face structure and the recurrence graph are retained as separate
typed layers.

## 2. Five copies `P_6 x C_5`

Let the face index set be `C_5 = Z/5Z`. Before gluing, define

```text
V_raw = C_5 x T_6
E_raw = {((f,n,k),(f,n',k')) : ((n,k),(n',k')) in E_6}.
```

There are `5*28=140` raw face positions and `5*42=210` raw directed edge
incidences. A raw vertex is written `(f,n,k)`.

Here `P_6 x C_5` means five copies indexed by `C_5`; it is not a claim that
the recurrence graph uses a standard Cartesian, tensor or strong graph product.

## 3. Seam equivalence

For `f in C_5` and `1<=n<=6`, impose

```text
(f,n,n) ~ (f+1,n,0),
```

and identify the five apices

```text
(f,0,0) ~ (g,0,0)  for all f,g in C_5.
```

The exclusion of `n=0` from the first rule avoids recounting the already
identified apex. The relation `~` is the equivalence relation generated by
these pairs.

There is one apex class of size `5`, thirty non-apex seam classes of size `2`
(`6` levels on each of `5` seams), and seventy-five singleton interior
classes.

## 4. Open complexes `K_open(j)`

For `1<=j<=5`, take faces `0,...,j-1`, identify all their apices, and impose
only the consecutive seam relations

```text
(f,n,n) ~_open (f+1,n,0)
for 0<=f<j-1 and 1<=n<=6.
```

No relation is imposed between the terminal left side of face `0` and the
terminal right side of face `j-1`. The resulting typed quotient is
`K_open(j)`. In particular, `K_open(5)` is the five-face preclosure object.

The word *open* refers to the unpaired terminal radial seams. It does not mean
that vertices or edges are deleted.

## 5. Closed quotient `K_closed`

Starting from `K_open(5)`, add the six terminal identifications

```text
(4,n,n) ~ (0,n,0),  1<=n<=6.
```

Equivalently,

```text
K_closed = (V_raw / ~, E_closed, F, q, w),
```

where:

- `F=C_5` is the retained macro-face set;
- `q:V_raw -> V_raw/~` is the quotient map;
- `E_closed={(q(u),q(v)):(u,v) in E_raw}` is a set of directed edges, so
  coincident quotient edges are represented once;
- the face-incidence layer remembers every raw face position and all `210`
  raw edge incidences.

Thus `K_closed` is not merely an anonymous graph. It is a weighted directed
quotient graph together with its five Pascal-face incidence maps.

## 6. Weight and adjacency

For a quotient vertex `[f,n,k]`, define

```text
w([f,n,k]) = binom(n,k).
```

This is well-defined: every nontrivial non-apex class identifies only side
vertices, and both side weights equal `binom(n,0)=binom(n,n)=1`.

The directed adjacency function is

```text
A(u,v) = 1  iff  (u,v) in E_closed,
         0  otherwise.
```

The graph6 export uses the undirected symmetrization
`{u,v}` whenever `A(u,v)=1` or `A(v,u)=1`. Graph6 therefore fingerprints the
underlying simple graph in the declared node order; it does not replace the
weights, directions or face-incidence tables.

## 7. Preserved Pascal recurrence

For every face `f`, let

```text
q_f(n,k) = q(f,n,k).
w_f(n,k) = binom(n,k), with value 0 outside 0<=k<=n.
```

With the convention `binom(n,k)=0` outside `0<=k<=n`, the preserved
recurrence is

```text
w(q_f(n,k))
  = w_f(n-1,k-1) + w_f(n-1,k)
  = binom(n-1,k-1) + binom(n-1,k)
  = binom(n,k),
```

for each face and `1<=n<=6`. Here the two parent terms are evaluated in the
same face incidence, including a zero term at the sides.

This is deliberately a **facewise recurrence**. Summing every incoming edge
of the simple quotient graph would double-count incidences at glued seams and
is not the claimed operation.

## 8. `C_5` and `D_5` actions

On raw positions define

```text
r(f,n,k) = (f+1,n,k),
m(f,n,k) = (-f,n,n-k),
```

with face arithmetic modulo `5`. Both maps preserve the generated seam
relation and therefore descend to `K_closed`. They preserve levels, weights,
directed recurrence edges and macro-face incidences. They satisfy

```text
r^5 = e,
m^2 = e,
m r m = r^-1.
```

The ten maps `{r^a, m r^a : 0<=a<5}` form the typed automorphism group
`D_5` of order `10`, where *typed* means that weights, directions and the
five-face incidence structure are part of the object.

The supplied graph6 string is not presented as an exhaustive automorphism
certificate for the untyped simple graph after those structures are forgotten.

## 9. Canonical node order

The reference export uses this deterministic order:

```text
A;
then for n=1,...,6:
  S_n_0,...,S_n_4;
  I_0_n_1,...,I_0_n_(n-1),
  ...,
  I_4_n_1,...,I_4_n_(n-1).
```

`S_n_s` is the seam class containing `(s,n,n)` and `(s+1,n,0)`. The
identifier `I_f_n_k` denotes the singleton interior class of `(f,n,k)`.

This order is part of the serialization contract, not an assertion that node
labels are intrinsic to an arbitrary isomorphic copy.
