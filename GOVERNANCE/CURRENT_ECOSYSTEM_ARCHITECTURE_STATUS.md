## LUCY boundary

LUCY is not a system, Runtime, agent, renderer, persistence layer, semantic or
scientific authority, navigation layer, translator or decision owner. Its
current implementation is `NONE`. Existing Experience/NEXAHEDRON reflection
interfaces are not retroactively renamed LUCY.

Only this transition is adopted:

```text
HUMAN_REFLECTION
→ EXPLICIT_HUMAN_SUBMIT_OR_CONFIRM
→ FORMAL_REQUEST_BOUNDARY
```

LU-07 session context, LU-08 persistence and LU-09 system-generated steering
remain deferred. Any future presentation implementation requires its own Owner
decision and contracts.

## Research-to-architecture boundary

```text
closed, scoped Research evidence
→ exact candidate proposition
→ authority and boundary review
→ explicit affected-Owner decision
→ separately authorized implementation / validation / certification / release
```

No step grants the next by implication. A PASS, Labreport, ledger entry, hash,
visual or implementation does not itself create NEXAH normative truth or ORION
product authority.
