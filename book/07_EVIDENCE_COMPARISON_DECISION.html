05
Four typed returns

Eine Entscheidung braucht ihren richtigen Namen.

PASS

Gate erfüllt

Der vorab definierte positive Befund wird vom vollständigen Record getragen.

FAIL

Gate verfehlt

Die erforderliche Evidenz ist vorhanden, widerspricht aber dem Schwellenkriterium.

ABSTAIN

Record außerhalb Support

Das System verweigert eine bekannte Klasse, statt eine Antwort zu erfinden.

UNKNOWN / STOP

Entscheidung nicht identifizierbar

Coverage, Bindung oder Validität reichen nicht aus. Der Test wird nicht nachträglich repariert.
