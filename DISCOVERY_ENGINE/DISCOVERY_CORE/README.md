# DISCOVERY CORE

Minimal core of the NEXAH Discovery Engine.

This module extracts the **essential analytical pipeline** for understanding  
how dynamic systems generate structure and transitions.

---

## 🧠 Core Idea

Traditional analysis asks:

> Where are systems stable?

DISCOVERY CORE asks:

> **Where and how do systems transition?**

---

## 🔁 Core Pipeline
```text
Dynamics
→ Phase Space
→ Risk Field
→ Critical Points
→ Transitions
→ Structure
```

---

## 📦 Included Modules

### 1. Phase Space

- `phase_space_map.py`  
Creates the parameter space representation of the system.

---

### 2. Field Construction

- `risk_landscape.py`  
Builds the continuous risk/stability field.

- `resilience_landscape.py`  
Constructs global stability structure.

---

### 3. Core Analysis

- `resilience_analyzer.py`  
Extracts fundamental system metrics.

- `resilience_critical_point_finder.py`  
Detects instability points and boundaries.

---

### 4. Transitions

- `resilience_phase_transition_detector.py`  
Identifies regime changes and transitions.

---

### 5. Structural Extensions

- `collapse_basin_map.py`  
Maps collapse regions and irreversible states.

- `global_resilience_map.py`  
Scales analysis to global system views.

---

### 6. Law Discovery (Experimental)

- `resilience_law_discovery.py`  
Searches for structural patterns.

- `resilience_symbolic_law_finder.py`  
Attempts symbolic equation discovery.

---

## 🎯 Purpose

This module exists to answer one core question:

> **Do real transitions emerge from system dynamics?**

> **too stable**

- uniform phase classification  
- weak transition detection  
- limited navigation potential

- noise injection  
- nonlinear coupling  
- parameter expansion  

→ to force real phase transitions

> a **minimal experimental system**
