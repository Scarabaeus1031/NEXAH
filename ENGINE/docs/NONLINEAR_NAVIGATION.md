# Nonlinear Navigation Geometry

This module describes how navigation occurs in nonlinear dynamical systems.

## Key Structure

- Two stable regimes (lobes)
- One transition channel (central manifold)
- One critical point

## Core Insight

Navigation occurs through transition channels, not within stable regimes.

## Channel Dynamics

The transition channel acts as a corridor connecting stability basins.

## Control

A minimal control field can steer trajectories:

u = (-k*x, -k*y, 0)

This stabilizes trajectories near the channel.

## Spool Structure

The attractor contains a dissipative spiral structure:

- not random chaos
- but structured internal flow

## Interpretation for NEXAH

Nonlinear systems are navigable via:

- transition channels
- control fields
- internal spiral structures
