# 🗄️ Archived Engine Components

This directory contains earlier experimental implementations of the NEXAH kernel and related systems.

These components were developed during the **exploration phase** of the project.

---

## ⚠️ Status

- not part of the current core system  
- partially experimental  
- not actively maintained  

---

## 🧠 Context

These modules represent an earlier attempt to:

- formalize regime landscapes  
- build a general navigation kernel  
- integrate multiple analysis layers  

---

## 🔄 Current Direction

The project has shifted toward a **bottom-up approach**:

```text
dynamics → field → signal → navigation → convergence
```
The current working system is implemented in:

- `APPLICATIONS/`
- `nexah/`
- `FIELD_LAYER/`

---

## 🧭 Archived Idea Map

The archived components can be grouped into several research directions.

### 🔴 High Potential (Future Integration)

These ideas are strongly aligned with the current system and may be reintegrated later:

- navigation engines (trajectory steering, feedback control)  
- stability / attractor analysis  
- flow field reconstruction tools  
- transition detection and regime segmentation  

👉 These should be revisited after core validation.

---

### 🟡 Medium Priority (Exploration / Extension)

Interesting directions, but not essential for the core system:

- multi-agent navigation  
- policy-based decision systems  
- reinforcement learning approaches  
- hybrid navigation frameworks  

👉 These depend on a stable core system.

---

### 🔵 Low Priority (Long-Term / Research)

More abstract or experimental ideas:

- symbolic navigation layers  
- resonance / lattice systems  
- architecture search and generative systems  
- high-dimensional topology / spectral analysis  

👉 These are valuable, but not required for validation.

---

### ⚪ Experimental / Unstructured

- rapid prototypes  
- partial implementations  
- exploratory scripts  

👉 kept for reference only.
