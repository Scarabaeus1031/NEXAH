# NEXAH Testkits

This directory contains reusable gates that separate demonstrable software
behavior from stronger scientific or operational claims.

## Current entry point

- **[Observed-Evidence Testkit](observed_evidence/README.md)** — Phase V
  protocol for benchmark models, computations, measurements, scenarios, and
  observed outcomes.

Testkits are stricter than showcases. A showcase explains a result; a testkit
defines what evidence must exist before the repository may name that result.
