# NEXAH Licensing Scope

NEXAH is a mixed-material repository. Licenses follow the responsibility and
provenance of each component rather than applying one undifferentiated license
to every file.

| Material | Default license | Scope |
| --- | --- | --- |
| Software, tests, configuration, and implementation code | [Apache License 2.0](LICENSE) | Original NEXAH software unless a file states otherwise |
| Original documentation and repository research material | [CC BY 4.0](LICENSE-DOCS.md) | Original NEXAH prose, specifications, research records, and explanatory material unless a file states otherwise |
| Third-party or source-derived material | Its stated source license | Not relicensed by NEXAH |
| Datasets, media, Library Works, and released artifacts with local terms | Their local license or provenance record | Local terms take precedence over repository defaults |

## Interpretation

Repository location alone does not change a component's license. Moving,
indexing, reviewing, or referencing an artifact does not relicense it.

Source records and artifact-specific notices must remain attached or directly
linked when material is copied, adapted, or redistributed. If no license is
stated for third-party material, do not assume that repository access grants
permission to reuse it.

## Contributions

Contribution licensing follows the destination and material type described in
[CONTRIBUTING.md](CONTRIBUTING.md). Contributors must identify externally
sourced material and confirm that they have the right to submit it under the
applicable terms.

## Citation

Licensing and citation are separate obligations. Use [CITATION.cff](CITATION.cff)
for the NEXAH software distribution and follow local provenance or citation
records for research, specifications, datasets, Library Works, and other
artifacts.
