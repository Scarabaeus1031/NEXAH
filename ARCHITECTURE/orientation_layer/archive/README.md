# Orientation Architecture Archive

This directory is reserved for superseded Orientation Layer specifications and
historical architecture artifacts.

Historical artifacts may contain aspirational capabilities, obsolete
terminology, or outdated maturity claims. They are preserved as design history
and are not normative descriptions of the current implementation.

Research hypotheses, active experiments, operator implementations, and
validation evidence do **not** belong here. They remain in the appropriate
`RESEARCH`, `PROTO_CORE`, `APPLICATIONS`, or experimental area.
