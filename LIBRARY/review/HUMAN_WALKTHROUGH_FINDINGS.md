# NEXAH Library — Human Walkthrough Findings

**Live public Are.na walkthrough · Reader perspective**

This review records what a first-time reader can actually see and follow. It is
not an API inventory and does not evaluate hidden metadata alone.

## Finding 1 — The entrance is not visible from the Library landing page

The public Channels page currently presents recently updated Channels first. In
the observed session, `INNER WORLD` and `LOGARITHMIC UNIVERSE` were visible,
while `START` was not the primary entrance.

Implication: the Library has an entry architecture, but Are.na does not expose
that architecture automatically. A reader can miss the intended beginning.

## Finding 2 — START reaches the Visitor’s Guide

`01 — NEXAH · START · CORE ORIENTATION` contains a visible Channel connection
to `THE VISITOR’S GUIDE`. This transition works.

## Finding 3 — The Visitor’s Guide explains, but does not route

The Visitor’s Guide clearly explains the Library Rooms and the principle of
curiosity-led navigation. In the visible public interface, however, it offers no
clickable Channel transition to:

- THE LANGUAGE BOOK
- GEOMETRIA NOVA
- THE LANGUAGE ATLAS
- THE OPERATOR’S HANDBOOK

Implication: the conceptual path exists, but the reader cannot walk it without
returning to search or knowing the destination in advance.

## Finding 4 — Language should be tested before Geometria

`THE LANGUAGE BOOK` promises seven simple lessons, a visual vocabulary, and an
explicit “How to read this book” entry. `GEOMETRIA NOVA` begins with a complete
continuum spanning geometry, dynamics, architecture, knowledge ecosystems, and
the observer.

Reader hypothesis:

```text
START
→ Visitor’s Guide
→ Language Book
→ Geometria Nova
→ Language Atlas
→ Operator’s Handbook
```

This is more pedagogical than placing Geometria before the vocabulary layer.

## Finding 5 — Operator Map is a useful bridge

`THE OPERATOR` introduces the full architecture. `THE OPERATOR MAP` behaves like
an accessible visual Field Guide. `THE OPERATOR’S HANDBOOK` then asks the reader
to work through twenty operations.

Stronger Builder hypothesis:

```text
Operator
→ Operator Map
→ Operator’s Handbook
→ Operator Library
```

The Map appears to be a bridge, not an ending.

## Finding 6 — Morphology to Mathematica is an abrupt domain jump

`FIELD ATLAS III — MORPHOLOGY` moves across visible patterns in physics,
biology, ecology, medicine, information, and cosmology. `NEXAH MATHEMATICA I`
immediately enters modular residues, prime distributions, polar drift fields,
and recursive arithmetic.

`NEXAH ATLAS — THE OPERATIONAL GEOMETRY OF TRANSITION` should be tested as a
bridge before Mathematica I.

## Finding 7 — Editorial residue in Morphology

The public description ends with the German editorial fragment:

> Ich finde, das passt inzwischen sehr gut zur gesamten Reihe:

This should enter a manual Are.na cleanup queue. No automatic write is authorized.

## Reader-level conclusion

The main failure is not taxonomy. It is traversability:

1. the intended entrance is not visually privileged;
2. the Visitor’s Guide does not link onward;
3. several strong conceptual sequences are not yet clickable paths;
4. transitions between domains need bridge Works;
5. Reader Mode needs pedagogical policy rather than raw score order.

These findings block permanent Reading Paths and Registry growth until reviewed.
