# Phase VIII — Public Navigation Recommendations

## Navigation grammar

Use these labels consistently:

| Label | Use |
|---|---|
| `Beginner →` | first useful Work for a new visitor |
| `Builder Path →` | entrance into construction and operational language |
| `Continue →` | next step in an accepted Reader Journey |
| `Next Volume →` | next member of a confirmed linear Series |
| `Bridge →` | Work that explains a domain transition |
| `Reference →` | optional lookup branch that does not interrupt the main path |
| `Explore further →` | open browsing outside a required sequence |

Do not use `canonical`, `proposal`, `object family`, Registry IDs, Operator IDs,
confidence values, or validation terminology in public navigation blocks.

## Placement

- Place the label immediately before the connected Channel.
- Keep one main continuation per Work where possible.
- Place optional references after the main continuation.
- Keep navigation blocks visually small; they should not compete with the Work.
- Do not duplicate full descriptions inside continuation blocks.

## Reader orientation sentence

Every major landing page should answer three questions in no more than three
short lines:

```text
Where am I?
What is this room for?
Where can I go next?
```

Example for START:

```text
You are at the main entrance to NEXAH.
Choose a path by what you want to understand.
You can return here whenever you want to change direction.
```

## Symbols

Do not add the proposed colored-circle system in the P0/P1 pass. Use plain text
labels first. Existing symbols may remain part of Work titles, but they should
not be treated as a controlled navigation code.

## Change discipline

- Add links; do not change identity.
- Remove only the explicitly confirmed Morphology residue.
- Do not rename, merge, or delete Channels.
- Do not reorder content beyond the small navigation section without a separate
  human decision.
- Execute and verify one journey batch at a time.

## Recommended batch order

1. P0: START entrance, Visitor’s Guide exits, Morphology cleanup.
2. P1 Beginner links.
3. P1 Builder links.
4. P1 Research links.
5. Re-run live verification.
6. Consider P2 index and confirmed-Series proposals separately.
